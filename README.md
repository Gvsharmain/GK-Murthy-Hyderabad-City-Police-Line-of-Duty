# G.K. Murthy Case Record — Website V2

This is a free static website designed as a documentary portal for the case of Late Sri G. Krishna Murthy.

## Files
- index.html
- style.css
- script.js
- documents/README.txt

## What V2 adds
- Dedicated Compassionate Appointment section (2001–2022 + 2026 continuation)
- Separate Line of Duty section
- Master 1985–2026 timeline
- Public Evidence Index with publication-safe filenames
- Present Status section
- Search/filter for evidence
- Explicit distinction between documentary fact, family position and pending administrative examination

## Important: actual PDFs
The File Library documents are not automatically public website files. Before publishing, download the desired source PDFs, redact sensitive information, rename them according to the Evidence Index, place them in `documents/`, and add links in `index.html`.

Do not publish:
- Aadhaar/identity numbers
- bank details
- phone numbers
- signatures
- unnecessary residential details
- third-party personal information

## Free publishing
GitHub Pages:
1. Create a GitHub account and repository.
2. Upload the contents of this folder.
3. Settings → Pages → deploy from the `main` branch / root.
4. Use the free `github.io` address.

Cloudflare Pages is another free static-hosting option.
